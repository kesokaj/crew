# Section 21: every recovery path, and the test that shows it

This matrix takes each row of section 21, "Failure handling", of the design (`docs/plan/agent-kanban-tdd.md`, version 1.26), in the design's order, and names the test that shows Crew's response, as M11 asks ("The recovery paths of section 21 are tested"). Go tests are named by their function, with their file under `internal/` unless the path says otherwise; browser tests are files in `tools/e2e/browser/tests/`; `tools/install-test/inside.sh` is run by `make install-test` on a fresh virtual machine with KVM, not by `make check`. Status is `tested` (a test exercises the path), `owned by Mn` (a later milestone builds the part, per the build plan and section 23), or `missing` (the part exists in the code now, or belongs to a milestone already done, and no test exercises the row's behaviour; where the behaviour is not built either, the cell says so). A row with several parts names a test for each tested part and names the part that is not tested; a row is `missing` when any part of it that is not owned by a later milestone has no test. Rows 1 to 81 are the first table, rows 82 to 89 the table "Added in 0.20".
